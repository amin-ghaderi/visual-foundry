# PMPI-MASTER-V10

Official editorial Instagram Master for **پارمان پادشاهی ایرانیان / Iranian Monarchy Party**.

**Do not design. Populate the Master.**

## Correct workflow

1. Select **PMPI-MASTER-V10**.
2. Duplicate it for the new project (clone the five Figma frames in `1Hlx23O0YeWSPJ5NgMBZWg`).
3. Never edit the canonical Master directly.
4. Populate new content.
5. Reflow only when necessary.
6. Export final assets (native PNG, scale 2, 2160 × 2160).
7. Keep the Master unchanged.

## Files

| File | Role |
|---|---|
| `MASTER_TEMPLATE.md` | Identity, Figma IDs, brand lines |
| `DESIGN_SPEC.md` | Locked geometry, color, type, header/footer |
| `CONTENT_RULES.md` | What may change vs what must not |
| `preview-master-v10.png` | Locked visual snapshot of frame `2:2` |
