## Workflow

```text
INPUT
→ READ / ANALYZE
→ EXTRACT CONTENT
→ STRUCTURE CONTENT
→ PREPARE SLIDE COPY
→ DUPLICATE FERDOWSI MASTER
→ POPULATE CONTENT
→ CHECK TYPOGRAPHY / PERSIAN TEXT
→ EXPORT
→ VERSION
```

Content determines the slide structure. Design does not determine the content.

Do not design as soon as files appear in `input/`. Read and organize first. Do not invent unsupported claims. Do not normalize Persian. Preserve supplied diacritics, نیم‌فاصله, and punctuation exactly.

On each duplicate, only these may change:

1. Verse / body text
2. Glossary
3. به زبان امروز
4. Source / story
5. Sequential number (`FOOT_NUM`)

Everything else is locked.
